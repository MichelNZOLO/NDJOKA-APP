Télécharger l'application (Android) Guide de démarrage

1. Télécharger l'application

NDJOKA fonctionne sur Android. Ouvrez ce lien depuis le téléphone qui servira à la caisse :

ndjoka.apk (dernière version)

Avertissement Android : le téléphone demandera d'autoriser l'installation depuis une source inconnue. C'est normal pour une application qui n'est pas passée par le Play Store. Autorisez-la une seule fois, dans les paramètres de votre navigateur.

2. Installer

  1. Ouvrez le fichier ndjoka.apk téléchargé.
  2. Si Android le demande, autorisez l'installation depuis ce navigateur.
  3. Appuyez sur Installer, puis ouvrez NDJOKA.
  4. Pour une mise à jour, réinstallez simplement le nouveau fichier par-dessus l'ancien : vos données sont conservées.

3. Démarrer

Créer votre bar

Ouvrez l'application et inscrivez-vous en tant que gérant. Vous bénéficiez d'un essai gratuit de 14 jours avec toutes les fonctionnalités.

Ajouter votre équipe

Chaque membre du personnel se connecte avec un code du bar et son identifiant et code PIN à 6 chiffres. Le gérant crée ces accès depuis l'application.

Prendre une commande

Choisissez la table, ajoutez les produits, puis encaissez. Les commandes restent ouvertes tant que la table n'est pas réglée.

Suivre la caisse et le stock

Les rapports et l'inventaire se trouvent dans l'application, dans les onglets dédiés.
